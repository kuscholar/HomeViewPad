# Community code of conduct

Treat contributors and users with respect, regardless of background, identity, experience, disability, or preferred language. Be specific and constructive in technical feedback. Assume good intent while taking reported harm seriously. Respect privacy and licensing.

Harassment, threats, discriminatory abuse, sexualized conduct, deliberate disruption, and sharing another person's private information are not acceptable in issues, pull requests, discussions, or other spaces representing this project.

Report a concern to the maintainer through a private contact listed on [their GitHub profile](https://github.com/kuscholar). If none is available, request a private contact without posting sensitive details. Security reports use [SECURITY.md](SECURITY.md). There is no guaranteed response time.

The maintainer will consider the context, protect reporter privacy where practical, and may request corrections, remove content, lock discussions, or restrict participation. Serious or repeated violations may result in a ban. Enforcement should be proportionate and explained privately when practical. Do not retaliate against good-faith reports.
